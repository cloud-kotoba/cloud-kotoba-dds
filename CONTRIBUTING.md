# Contributing

Read design-rules.md before changing UI. Keep the jp-go-dds foundation and its semantic token contract. Update source and generated preview together. Keep contracts.edn consistent with interaction-contracts.md. Clearly separate implemented behavior from proposed adapters.

Check the preview at 320, 390, 768 and 1440 CSS pixels. Exercise navigation, settings open/close and focus return, language changes, draft preservation, invalid input, running and recovery states. Do not introduce live authentication, billing or inference into a fixture preview.

Preserve third-party notices. Do not commit account data, credentials, machine-specific paths or personal conversation histories.
